Политика конфиденциальности

Издатель расширения — Mycelium. Поддержка и вопросы о данных: qobuz43@gmail.com. Эта политика относится к расширению Separate Window.

Назначение и используемые данные

Расширение открывает выбранный пользователем блок веб-страницы в отдельном окне. Для этого оно обрабатывает адрес и заголовок текущей вкладки, структуру страницы и CSS-селектор выбранного элемента. По запросу пользователя может создаваться снимок видимой области выбранного блока.

В локальном хранилище Chrome сохраняются адрес страницы, CSS-селектор блока и, по выбору пользователя, размер и положение окна. Во временном сессионном хранилище сохраняются адрес открытой страницы, идентификаторы вкладки и окон и исходное положение вкладки — для её возврата и восстановления после закрытия окна.

Куда передаются данные

Расширение не отправляет эти данные издателю, не использует сервер, рекламу или сервис аналитики и не продаёт данные. В нём нет учётных записей, внешних шрифтов и удалённо загружаемого исполняемого кода.

Снимок создаётся и сохраняется на устройстве пользователя как PNG только по его команде. По кнопке закладки расширение создаёт запись в папке Chrome «Separate windows». Название закладки и ссылка могут синхронизироваться самим Chrome, если пользователь включил синхронизацию браузера. Передача и хранение данных синхронизации регулируются настройками и политиками браузера.

Открытая веб-страница продолжает выполнять собственные сетевые запросы; при восстановлении после закрытия окна она загружается заново. Сайты, которые посещает пользователь, работают по своим политикам. При переходе по ссылкам помощи или политики открывается соответствующая публичная страница GitHub; это отдельная навигация пользователя.

Содержимое страниц и снимков

Содержимое выбранного блока или снимка может включать личную и иную чувствительную информацию, уже отображаемую сайтом. Расширение не извлекает специально пароли, сообщения, платёжные или медицинские данные. Оно использует выбранное содержимое только для отображения в окне или создания запрошенного снимка, без передачи разработчику.

Управление и удаление

Команда «Забыть выбор для этой страницы» удаляет сохранённый селектор и размеры для текущего адреса. Удаление расширения удаляет его браузерное хранилище. Временное состояние переноса очищается после возврата или восстановления вкладки и при завершении браузерной сессии. Сохранённые PNG и созданные закладки остаются под управлением пользователя и удаляются отдельно.

Ссылка на блок содержит адрес исходной страницы и CSS-селектор. Делитесь такой ссылкой только если можно делиться исходным адресом страницы.

Использование разрешений

Доступ к сайтам нужен для выбора и изоляции элементов, повторного открытия сохранённого блока и снимков. Доступ к вкладкам нужен для переноса, определения последнего адреса и восстановления страницы. Хранилище сохраняет перечисленные настройки. Scripting подключает только упакованный код к уже открытым страницам. Контекстное меню запускает выбор. Доступ к закладкам используется для поиска или создания папки «Separate windows» и добавления записи по команде пользователя.

Privacy policy

The extension publisher is Mycelium. For support and data questions contact qobuz43@gmail.com. This policy covers the Separate Window browser extension.

Purpose and data used

Separate Window opens a user-selected page element in a separate window. It processes the current tab URL and title, the page structure and the selected element's CSS selector. At the user's request it can capture the visible part of the selected element.

Chrome local storage contains page URLs, CSS selectors and optionally window size and position. Temporary session storage contains the current page URL, tab and window identifiers and the tab's original position, to return or recover the tab after the popup closes.

Where data goes

The extension does not send this data to its publisher. It has no server, advertising, analytics service, user accounts, remote fonts or remotely hosted executable code. Data is not sold.

A screenshot is created and saved on the user's device as a PNG only on request. The bookmark button creates an entry in Chrome's “Separate windows” folder. Chrome itself may synchronize bookmark titles and links if browser synchronization is enabled. Browser sync is governed by the browser's settings and policies.

The original website continues to make its own network requests, and the page reloads when recovered after a native window close. Visited websites have their own policies. Opening the help or privacy link navigates to the relevant public GitHub page as a separate user action.

Page and screenshot content

A selected element or screenshot may contain personal or sensitive information already displayed by the website. The extension does not specifically extract passwords, messages, payment details or health data. Selected content is used only to display the element or create the requested screenshot, without transmission to the developer.

Control and deletion

“Forget selection for this page” removes the saved selector and geometry for the current URL. Uninstalling the extension removes its browser storage. Temporary transfer state is cleared after returning or recovering the tab and at the end of the browser session. Saved PNG files and created bookmarks remain under the user's control and are deleted separately.

An element link includes the source page URL and its CSS selector. Share it only when it is appropriate to share that page URL.

Permissions

Website access enables selection, isolation, saved-element reopening and screenshots. Tab access enables moving tabs, tracking the latest URL and recovering the page. Storage holds the settings described above. Scripting injects packaged code into existing pages. The context menu starts selection. Bookmark access finds or creates the “Separate windows” folder and adds a bookmark at the user's request.
