# Изображение для поиска

Загрузочные файлы: **`assets/promo-440x280.png`** (малое рекламное изображение) и **`assets/promo-1400x560.png`** (большое рекламное изображение). Для каждого размера своя композиция. Пакет расширения для этой замены обновлять не требуется.

## Что изменилось

Крупно указано название **Separate Window** и подпись **«Video (and more) in a separate window :)»**. В малом формате текст сверху, в широком — слева. Показано действие: на загруженной баннерами странице выделен плеер; стрелка ведёт к отдельному чистому окну с видео. Калькулятор убран по запросу пользователя. Синий фон сохраняет связь с иконкой продукта, а яркое изображение озера выделяется в светлом интерфейсе магазина.

Рекламные изображения общие для всех языков. По запросу пользователя оба используют английскую подпись со смайликом. Уменьшение малого изображения до 220×140 сохраняет читаемость названия и подписи, силуэты страницы, выделения, стрелки и отдельного окна. Это промоиллюстрация возможностей, не снимок реального интерфейса Chrome. Предполагаемая заметность не подтверждена A/B-тестом.

## Основания

- [Supplying Images](https://developer.chrome.com/docs/webstore/images): размер 440×280; рекомендации проверять уменьшение вдвое, использовать насыщенные цвета и учитывать светло-серый фон магазина. Рекомендация избегать текста не применена по прямому запросу пользователя: название и объяснение обязательны для этой версии.
- [Store listing](https://developer.chrome.com/docs/webstore/cws-dashboard-listing): малое и большое рекламные изображения не локализуются.

## Исходник и воспроизводимость

Иллюстрации созданы встроенным инструментом **imagegen**, без сторонних фотографий и логотипов. Мастера: `source/search-tile-master.png` и `source/marquee-master.png`. Полные запросы: `source/search-tile-prompt.txt` и `source/marquee-prompt.txt`. Подготовка размеров и RGB выполнена FFmpeg без повторной генерации.

```powershell
python tools/promo_tile.py
python tools/package.py
```

Нужны зависимости из `tools/requirements-video.txt` и Pillow. Иконка, галереи и код расширения не менялись.

В кабинете Chrome Web Store замените изображения в полях **«Маленькое рекламное изображение»** и **«Очень большое рекламное изображение»**, сохраните карточку и отправьте изменение на проверку. Файлы подготовлены локально; в магазин автоматически не отправлены.
