# Изображение для поиска

Загрузочный файл: **`assets/promo-440x280.png`**. Это малое рекламное изображение, а не иконка 128×128 и не первый скриншот галереи. Оно заменяет прежнюю абстрактную иллюстрацию двух окон. Пакет расширения для этой замены обновлять не требуется.

## Что изменилось

Сверху крупно указано название **Separate Window** и прямое объяснение **«Видео в отдельном окне»**. Ниже показано действие: на загруженной баннерами странице выделен плеер; стрелка ведёт к отдельному чистому окну с видео. Калькулятор убран по запросу пользователя. Синий фон сохраняет связь с иконкой продукта, а яркое изображение озера выделяется в светлом интерфейсе магазина.

Малое рекламное изображение общее для всех языков. По выбору пользователя использована русская объясняющая подпись; она будет видна и в других локалях. Уменьшение до 220×140 сохраняет читаемость названия и подписи, силуэты страницы, выделения, стрелки и отдельного окна. Это промоиллюстрация возможностей, не снимок реального интерфейса Chrome. Предполагаемая заметность не подтверждена A/B-тестом.

## Основания

- [Supplying Images](https://developer.chrome.com/docs/webstore/images): размер 440×280; рекомендации проверять уменьшение вдвое, использовать насыщенные цвета и учитывать светло-серый фон магазина. Рекомендация избегать текста не применена по прямому запросу пользователя: название и объяснение обязательны для этой версии.
- [Store listing](https://developer.chrome.com/docs/webstore/cws-dashboard-listing): малое и большое рекламные изображения не локализуются.

## Исходник и воспроизводимость

Новая иллюстрация создана встроенным инструментом **imagegen**, без сторонних фотографий и логотипов. Мастер: `source/search-tile-master.png`. Полный запрос: `source/search-tile-prompt.txt`. Подготовка размеров и RGB выполнена FFmpeg без повторной генерации.

```powershell
python tools/promo_tile.py
python tools/package.py
```

Нужны зависимости из `tools/requirements-video.txt` и Pillow. Большое промо 1400×560, иконка, галереи и код расширения не менялись.

В кабинете Chrome Web Store замените изображение в поле **«Маленькое рекламное изображение»**, сохраните карточку и отправьте изменение на проверку. Файл подготовлен локально; в магазин автоматически не отправлен.
