## Название

Separate Window

## Краткое описание

Открывайте видео, виджеты и другие блоки страницы в отдельном окне. Без перезагрузки, рекламы и лишнего фона.

## Полное описание

Separate Window открывает выбранную часть веб-страницы в отдельном окне. Это удобно для видео, виджетов, игр, таблиц и других интерактивных блоков.

Нажмите значок расширения, выберите «Выбрать блок на странице» и наведите курсор на нужную область. Колесо мыши расширяет или уменьшает выбор; щелчок открывает блок в отдельном окне. Esc отменяет выбор.

Возможности:
- Перенос текущей вкладки в отдельное окно без перезагрузки страницы.
- Только выбранный блок: оформление и фон окружающей страницы временно скрываются.
- Полупрозрачные кнопки поверх содержимого, которые появляются при наведении.
- Возврат живой страницы во вкладку кнопкой «Во вкладку».
- Восстановление страницы обычной вкладкой после закрытия отдельного окна крестиком.
- Сохранение размеров и положения окна для конкретной страницы.
- Масштаб, поворот, яркость и полноэкранный режим.
- Снимок видимой области блока в PNG.
- Закладки в папке «Separate windows» и ссылки для повторного открытия выбранного блока.
- Быстрый вызов Alt+Shift+S и команда в контекстном меню.
- Русский и английский интерфейс.

Расширение работает локально: без регистрации, рекламы, аналитики и передачи данных разработчику. Выбор блоков и размеры окон сохраняются в браузере. Созданные закладки могут синхронизироваться самим Chrome, если включена синхронизация.

Учитывайте ограничения:
- Закрытие крестиком восстанавливает страницу с перезагрузкой. Для сохранения работы без перезагрузки используйте «Во вкладку».
- Обычное окно не закрепляется поверх всех приложений.
- Встроенный iframe выбирается целиком. Совместимость с каждым сайтом и DRM-плеером не гарантируется.
- Расширения недоступны на служебных страницах Chrome и в Chrome Web Store.

Это независимая реализация. Расширение не связано с автором оригинального Separate Window 0.9.5; его исходный пакет и графические материалы не используются.
