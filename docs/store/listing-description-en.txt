Separate Window opens a selected part of a web page in its own window. Use it for videos, widgets, games, tables and other interactive page elements.

Click the extension icon, choose “Select a page element” and point at the desired area. Scroll to expand or reduce the selection; click to open it. Press Esc to cancel.

Features:
- Move the current tab into a popup without reloading the page.
- Show only the selected element; temporarily hide surrounding page decoration.
- Translucent controls appear over the content when you hover over their area.
- The semi-transparent “Open in a separate window” button appears only when you hover over a saved element, keeping the page visible underneath.
- Video-only mode hides player panels; “Show player” restores site controls without reloading. Also supports accessible HTML video inside nested frames.
- “Always on top” opens video in Chrome picture-in-picture, including videos in nested players.
- Return the live page to a regular tab with “Back to tab”.
- Recover the page as a regular tab after closing the popup with its native close button.
- Remember window size and position for individual pages.
- Zoom, rotation, brightness and full-screen mode.
- Save the visible part of an element as a PNG screenshot.
- Create bookmarks in “Separate windows” and links that reopen the selected element.
- Alt+Shift+S shortcut and a native context-menu command.
- Choose Russian, English or your browser language in the extension menu. The preference is saved and applies to existing windows without reloading video.

The extension runs locally, with no registration, ads, analytics or data sent to the developer. Element selections and window geometry are stored in the browser. Chrome itself may sync created bookmarks when browser sync is enabled.

Limitations:
- Native close recovers the page by reloading it. Use “Back to tab” to keep the live page without reloading.
- Only video floats above other applications in a separate PiP window with Chrome controls. Site controls and subtitles may not appear; some players block PiP. The regular popup containing an arbitrary element is not pinned.
- Embedded iframes are selected as a whole. Compatibility with every website or DRM player is not guaranteed.
- Chrome internal pages and the Chrome Web Store restrict extension access.
