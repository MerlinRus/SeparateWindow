# Separate Window

Расширение Mycelium для открытия выбранного блока страницы в отдельном окне. Manifest V3, русский и английский интерфейс, без серверов, рекламы, аналитики и внешних зависимостей. Реализация написана заново по публичному описанию Separate Window 0.9.5 (Alek), без его исходного пакета и графических материалов. Не связано с автором оригинала.

![Separate Window](icons/icon128.png)

Материалы и инструкция публикации: [docs/store/README.md](docs/store/README.md). Сборка чистого ZIP для Chrome Web Store: `python tools/package.py`; результат — `dist/separate-window-1.3.1.zip`. Отдельный архив с изображениями и текстами — `dist/chrome-web-store-materials-1.3.1.zip`.

## Установка в Chrome

1. В этом репозитории нажмите **Code → Download ZIP** и распакуйте архив в постоянную папку. Также можно клонировать репозиторий: `git clone https://github.com/MerlinRus/SeparateWindow.git`. Не удаляйте и не перемещайте папку после установки.
2. Введите `chrome://extensions` в адресную строку.
3. Включите **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой лежит `manifest.json`.
5. Через кнопку расширений (пазл) закрепите **Separate Window**.
6. Если сайт был открыт до установки, один раз обновите вкладку. В большинстве случаев расширение также умеет подключаться через свою кнопку без обновления.

В Edge установка аналогична, страница расширений — `edge://extensions`.

## Использование

Нажмите значок расширения → **Выбрать блок на странице**. Наведите мышь на видео, виджет, игру, изображение, таблицу или другой блок.

- Прокрутка вниз расширяет выбор до родительского контейнера; вверх возвращает к меньшему блоку.
- Щелчок левой кнопкой выносит блок в отдельное окно. Esc или кнопка «Отмена» отменяют выбор.
- В режиме выбора прозрачный слой перехватывает нажатия поверх плееров и iframe. Клик выбора не должен переключать воспроизведение. После выбора или отмены слой удаляется и управление плеером работает как обычно.
- Для видео можно выбрать весь контейнер или iframe плеера: если видео занимает основную часть блока, режим «Только видео» убирает панели сайта и встроенные кнопки видео. «Показать плеер» возвращает их без перезагрузки. Небольшие видео внутри обычного виджета не изолируются автоматически.
- Можно начать выбор через контекстное меню страницы или сочетанием **Alt+Shift+S**. Если сочетание занято, измените его в `chrome://extensions/shortcuts`.

В отдельном окне доступны:

Выбранный блок использует всю область окна. Кнопки полупрозрачные, расположены поверх содержимого в правом верхнем углу и появляются только при наведении на их область. Когда курсор уходит, кнопки исчезают; отдельной полосы и отступа под них нет. Для управления с клавиатуры кнопки также появляются при фокусе через Tab; Esc снимает фокус. На снимки кнопки не попадают.

| Управление | Действие |
| --- | --- |
| ↩ Во вкладку | Возвращает исходную страницу и её вёрстку без перезагрузки |
| Показать плеер / Только видео | По умолчанию скрывает панели видеоплеера, оставляя кадр. Переключатель временно возвращает выбор серий, качество и остальные элементы сайта |
| 📌 Поверх всех / Вернуть видео | Открывает видео из выбранного блока в системном окне «картинка в картинке» поверх остальных приложений; повторное нажатие возвращает видео |
| Размер | Запоминает размер и положение окна для этой страницы; повторное нажатие удаляет сохранение |
| − / + | Уменьшает / увеличивает блок |
| Вписать / 1:1 | Переключает вписывание в окно и исходный масштаб |
| ↻ | Поворачивает на 90° |
| Яркость | Меняет яркость выбранного блока |
| Снимок | Сохраняет видимую часть блока в PNG |
| ★ | Создаёт закладку в папке **Separate windows** |
| Ссылка | Показывает ссылку для открытия выбранного блока; выделенную ссылку можно скопировать Ctrl+C |
| ⛶ | Включает / выключает полный экран |

При повторном заходе кнопка **↗ В отдельное окно** появляется возле сохранённого блока только при наведении на него или при фокусе с клавиатуры. Когда курсор уходит, кнопка скрывается. Ссылка или закладка расширения открывают блок автоматически, в том числе если он появляется с задержкой до 15 секунд. Эти ссылки работают только в браузере с установленным аналогом.

Чтобы удалить выбор и сохранённые размеры для страницы: значок расширения → **Забыть выбор для этой страницы**.

## Как сохраняется работа страницы

В отдельное окно переносится **сама вкладка**. Элемент остаётся в прежнем DOM, остальная страница временно скрывается стилями. Сохраняются обработчики событий, состояние JavaScript и документ iframe. Когда в исходном окне была единственная вкладка, временно появляется пустая вкладка; при возврате она удаляется, если вы её не использовали.

Фоны, рамки, тени и декоративные псевдоэлементы родительских контейнеров временно убираются. Плеер центрируется относительно окна; пространство вне его занимает чёрный фон. При возврате во вкладку исходное оформление восстанавливается.

Кнопка **↩ Во вкладку** возвращает живую страницу без перезагрузки. Если закрыть отдельное окно крестиком, расширение автоматически восстановит страницу обычной вкладкой в исходном окне и уберёт временную пустую вкладку. Если исходного окна уже нет, используется другое обычное окно или создаётся новое. Закрытие крестиком уничтожает документ средствами Chrome, поэтому страница при восстановлении загружается заново; состояние JavaScript и позиция воспроизведения не гарантируются. Для сохранения воспроизведения без перезагрузки используйте **↩ Во вкладку**.

## Совместимость и отличия

- Требуется Chromium 120+. Автоматическая проверка выполнена в Chromium с настоящим распакованным расширением.
- Это независимый аналог с перечисленными функциями, а не побайтовая копия старого расширения. Старые закладки, настройки и формат ссылок оригинала не импортируются.
- Chrome запрещает расширениям работать на служебных страницах, в Chrome Web Store и в некоторых встроенных просмотрщиках. Для `file://` включите доступ к файловым URL в свойствах расширения.
- Встроенный iframe выбирается целиком. Выбор внутренних элементов чужого iframe и закрытого Shadow DOM не поддерживается: выбирайте внешний контейнер.
- Сложные сайты могут заменять выбранный элемент при навигации или менять поведение при изменении размеров окна. В этом случае верните страницу и выберите блок заново. Индивидуальная совместимость со всеми плеерами, DRM, играми и сайтами не гарантируется.
- При увеличении сверх границ окна снимок сохраняет только видимую часть. DRM-видео может попасть на снимок чёрным.
- Кнопка **📌 Поверх всех** использует встроенный режим Chrome «картинка в картинке» для видео, в том числе во вложенном iframe. Исходный плеер и вкладка остаются открытыми; видео не переносится в другой DOM и не перезагружается. В PiP доступны элементы управления Chrome; кнопки сайта, субтитры, яркость и поворот из нашего окна могут не отображаться. Закрытие PiP возвращает видео в плеер. Сайты и DRM могут запрещать этот режим. Для картинок, игр и прочих блоков он недоступен; само обычное окно Chrome не закрепляется.
- Сохранённое положение окна может потребовать повторного выбора при изменении конфигурации мониторов.

## Данные и разрешения

Все данные хранятся локально в браузере. Расширение не делает сетевых запросов. Ссылки содержат адрес страницы и CSS-селектор выбранного блока: делитесь ими только если можно делиться исходным адресом страницы.

- Доступ к сайтам нужен для выбора, скрытия окружающей страницы, автоматических ссылок и маркеров сохранённого выбора.
- `tabs` нужен для переноса и возврата вкладки и определения её адреса.
- `storage` сохраняет выбор и размеры; состояние переноса хранится в `storage.session` и переживает остановку service worker.
- `scripting` подключает управление к уже открытым вкладкам.
- `contextMenus` добавляет команду в контекстное меню.
- `bookmarks` создаёт папку и закладки по кнопке ★.
- Доступ к сайтам также позволяет делать снимки по вашей команде; отдельное избыточное разрешение `activeTab` не запрашивается.

## Проверка для разработки

Сборка не нужна. Устанавливается непосредственно содержимое этой папки.

```powershell
node --check background.js
node --check content.js
node --check popup.js
python tests/smoke.py
python tests/pip.py
```

Для последней команды нужны Python с пакетом `playwright` и установленный Chromium Playwright (`python -m playwright install chromium`). Тест запускает отдельный временный профиль и локальный HTTP-сервер; личный профиль браузера не используется.

Тест проверяет выбор и колесо мыши, iframe с другого домена, перехват `pointerdown` и `click` без переключения воспроизведения, отмену с фокусом внутри iframe, перенос без перезагрузки, интерактивность блока, скрытую полупрозрачную панель, сохранение и удаление геометрии, снимок PNG, закладку и автоссылку, возврат исходной вёрстки, повторный визит, удаление выбора и восстановление вкладки после штатного закрытия отдельного окна, в том числе после перехода на другой адрес. PiP проверяется на обычном видео и во вложенном плеере с другого домена: сохранение документа и воспроизведения, исключение посторонних видео, возврат, закрытие PiP и запрет со стороны плеера. Скриншоты теста находятся в `tests/`.

Публичное описание оригинала: https://www.crx4chrome.com/extensions/cbgkkbaghihhnaeabfcmmglhnfkfnpon/

## Иконки и материалы магазина

Исходный знак — `icons/mark.svg`. PNG 16/32/48/128 для Chrome, 256/512 для презентаций и favicon.ico генерируются командой `python tools/build_icons.py`. Иконка 128×128 имеет номинальный прозрачный отступ 16 px.

`python tools/store_assets.py` снимает настоящий интерфейс на собственной демо-странице и создаёт шесть скриншотов RU/EN, промо 440×280 и 1400×560. `python tools/verify_release.py` проверяет комплект и загрузку упакованной версии в Chromium. Для генерации материалов нужны Python, Pillow и Playwright; в runtime-ZIP они не входят.
