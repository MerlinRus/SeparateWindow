# Separate Window

Расширение Mycelium для открытия выбранного блока страницы в отдельном окне. Manifest V3, русский и английский интерфейс, без серверов, рекламы, аналитики и внешних зависимостей. Реализация написана заново по публичному описанию Separate Window 0.9.5 (Alek), без его исходного пакета и графических материалов. Не связано с автором оригинала.

![Separate Window](icons/icon128.png)

Материалы и инструкция публикации: [docs/store/README.md](docs/store/README.md). Команда `python tools/package.py` собирает `dist/separate-window-1.5.1.zip` для Chrome Web Store и отдельный архив с изображениями и текстами `dist/chrome-web-store-materials-1.5.1.zip`. Результаты проверок плееров: [docs/player-checks.md](docs/player-checks.md).

Издатель: **Mycelium**. Поддержка: **qobuz43@gmail.com**. [Сайт Separate Window](https://separate.maark.ru/) · [Политика конфиденциальности](https://separate.maark.ru/privacy.html).

Исходники сайта лежат в `website/`. Команда `python website/build.py` собирает страницы на русском и английском и архив для выкладки. На сервере `sudo bash deploy.sh deploy separate-window-website.tar.gz` активирует новый выпуск в `/opt/separate-window`. Для первой настройки HTTPS используйте `sudo bash deploy.sh https`.

После новой установки можно пройти или пропустить обучение. Ссылка «Обучение» в меню открывает практику с видео, графиком и «Сапёром». `python website/build.py` и `python tests/onboarding.py` проверяют оба языка и реальные действия в Chromium.

Треугольные индикаторы в интерфейсе сайта и расширения запрещены. Для раскрывающихся блоков используйте плюс и минус.

## Установка в Chrome

1. В этом репозитории нажмите **Code → Download ZIP** и распакуйте архив в постоянную папку. Также можно клонировать репозиторий: `git clone https://github.com/MerlinRus/SeparateWindow.git`. Не удаляйте и не перемещайте папку после установки.
2. Введите `chrome://extensions` в адресную строку.
3. Включите **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой лежит `manifest.json`.
5. Через кнопку расширений (пазл) закрепите **Separate Window**.
6. Если сайт был открыт до установки, один раз обновите вкладку. В большинстве случаев расширение также умеет подключаться через свою кнопку без обновления.

В Edge установка аналогична, страница расширений — `edge://extensions`.

## Использование

Язык можно сменить кнопками **RU / EN** в шапке меню расширения. При первом запуске язык определяется браузером. Выбор сохраняется локально и применяется к меню, кнопкам на странице, открытым отдельным окнам, подсказкам, сообщениям и команде контекстного меню. Уже открытое видео не перезагружается. Системные подписи Chrome и язык страницы магазина определяются самим браузером.

Нажмите значок расширения → **Выбрать блок на странице**. Наведите мышь на видео, виджет, игру, изображение, таблицу или другой блок.

- Прокрутка вниз расширяет выбор до родительского контейнера; вверх возвращает к меньшему блоку.
- Щелчок левой кнопкой выносит блок в отдельное окно. Esc или кнопка «Отмена» отменяют выбор.
- В режиме выбора прозрачный слой перехватывает нажатия поверх плееров и iframe. Клик выбора не должен переключать воспроизведение. После выбора или отмены слой удаляется и управление плеером работает как обычно.
- При выборе кадра расширение по возможности выделяет плеер целиком. Его перемотка, качество и остальные штатные кнопки остаются доступны в отдельном окне. Колесом мыши по-прежнему можно выбрать более узкий или широкий блок.
- «Только видео» скрывает панели и встроенные кнопки, если видео занимает основную часть выбранного блока. «Показать плеер» возвращает их без перезагрузки.
- Можно начать выбор через контекстное меню страницы или сочетанием **Alt+Shift+S**. Если Chrome оставил сочетание пустым, нажмите «Назначить клавиши» в меню расширения. Если сочетание уже назначено, нажмите на него, чтобы изменить.

В отдельном окне доступны:

Выбранный блок использует всю область окна. Кнопки полупрозрачные, расположены поверх содержимого в правом верхнем углу и появляются только при наведении на их область. Когда курсор уходит, кнопки исчезают; отдельной полосы и отступа под них нет. Для управления с клавиатуры кнопки также появляются при фокусе через Tab; Esc снимает фокус. На снимки кнопки не попадают.

| Управление | Действие |
| --- | --- |
| ↩ Во вкладку | Возвращает исходную страницу и её вёрстку без перезагрузки |
| Только видео / Показать плеер | По желанию скрывает панели видеоплеера и возвращает их тем же переключателем |
| 📌 Поверх всех / Открепить | Открывает видео в режиме «Картинка в картинке», для других блоков показывает живой просмотр. Закрепление зависит от оконной системы |
| Размер | Запоминает размер и положение окна для этой страницы; повторное нажатие удаляет сохранение |
| − / + | Уменьшает / увеличивает блок |
| Вписать / 1:1 | Переключает вписывание в окно и исходный масштаб |
| ↻ | Поворачивает на 90° |
| Снимок | Сохраняет видимую часть блока в PNG |
| ★ | Создаёт закладку в папке **Separate windows** |
| Ссылка | Показывает ссылку для открытия выбранного блока; выделенную ссылку можно скопировать Ctrl+C |
| ⛶ | Включает / выключает полный экран |

При повторном заходе полупрозрачная кнопка **↗ В отдельное окно** появляется возле сохранённого блока только при наведении на него или при фокусе с клавиатуры. Когда курсор уходит, кнопка скрывается. Ссылка или закладка расширения открывают блок автоматически, в том числе если он появляется с задержкой до 15 секунд. Эти ссылки работают только в браузере с установленным аналогом.

В инкогнито выбор и размеры не сохраняются между открытиями окна. Закладка и PNG создаются только по вашей команде.

## Как сохраняется работа страницы

В отдельное окно переносится **сама вкладка**. Элемент остаётся в прежнем DOM, остальная страница временно скрывается стилями. Сохраняются обработчики событий, состояние JavaScript и документ iframe. Когда в исходном окне была единственная вкладка, временно появляется пустая вкладка; при возврате она удаляется, если вы её не использовали.

Для обычных блоков сохраняются измеряемые размеры родительских контейнеров: их обнуление может заставить динамический дашборд убрать панель из DOM. Если страница заменяет выбранный элемент или его контейнер при обновлении, расширение повторно находит блок по исходному селектору. Если блок удалён, расширение показывает исходную страницу и кнопку возврата. Сценарий проверен на локальной панели с ResizeObserver, обновлениями числа, кликами и перерисовкой.

При переносе карточки или виджета сохраняется цвет подложки, который был виден в исходной вкладке. Рамки, тени и другие украшения родительских контейнеров скрываются. Плеер центрируется на чёрном фоне. При возврате во вкладку исходное оформление восстанавливается.

Кнопка **↩ Во вкладку** возвращает живую страницу без перезагрузки. Если закрыть отдельное окно крестиком, расширение автоматически восстановит страницу обычной вкладкой в исходном окне и уберёт временную пустую вкладку. Если исходного окна уже нет, используется другое обычное окно или создаётся новое. Закрытие крестиком уничтожает документ средствами Chrome, поэтому страница при восстановлении загружается заново; состояние JavaScript и позиция воспроизведения не гарантируются. Для сохранения воспроизведения без перезагрузки используйте **↩ Во вкладку**.

## Совместимость и отличия

- Требуется Chromium 120+. Автоматическая проверка выполнена в Chromium с настоящим распакованным расширением.
- Это независимый аналог с перечисленными функциями, а не побайтовая копия старого расширения. Старые закладки, настройки и формат ссылок оригинала не импортируются.
- Chrome запрещает расширениям работать на служебных страницах, в Chrome Web Store и в некоторых встроенных просмотрщиках. Для `file://` включите доступ к файловым URL в свойствах расширения.
- Встроенный iframe выбирается целиком. Выбор внутренних элементов чужого iframe и закрытого Shadow DOM не поддерживается: выбирайте внешний контейнер.
- Сложные сайты могут заменять выбранный элемент при навигации или менять поведение при изменении размеров окна. В этом случае верните страницу и выберите блок заново. Индивидуальная совместимость со всеми плеерами, DRM, играми и сайтами не гарантируется.
- При увеличении сверх границ окна снимок сохраняет только видимую часть. DRM-видео может попасть на снимок чёрным.
- Кнопка **📌 Поверх всех** открывает основное видео блока во встроенном плеере Chrome. Это работает и во вложенных iframe внутри закрытых компонентов. Исходный плеер продолжает работать. Chrome может скрыть кнопки и субтитры сайта, а некоторые сайты запрещают этот режим.
- Для изображений, дашбордов и других блоков Chrome предлагает показать **эту вкладку**. Разрешите показ, чтобы увидеть выбранную область в живом окне поверх других приложений. Кнопки и поля остаются доступны в исходном окне, а живой просмотр показывает их изменения. Если после выбора Chrome просит ещё один щелчок, нажмите **Открыть просмотр**. Закрытие просмотра или возврат блока во вкладку останавливает показ.
- Живой просмотр запрашивает захват до 120 кадров/с. Фактическая плавность зависит от содержимого вкладки, Chrome и дисплея.
- В меню расширения включите **«Видео поверх окон»**, чтобы Chrome мог вынести играющее видео при переходе на другую вкладку. Настройка выключена по умолчанию и сохраняется отдельно для каждого HTTPS-сайта. Если Chrome спросит, разрешите автоматический режим. Доступность зависит от версии Chrome, настроек сайта и условий воспроизведения. Ручная кнопка «Поверх всех» также работает с поддерживаемыми встроенными плеерами.
- Размер живого просмотра сохраняется после изменения. При повторном открытии в той же вкладке Chrome может восстановить и положение. Геометрией встроенного видео-PiP управляет сам Chrome.
- Для живого просмотра на Windows нужен Chrome 156 или новее. На ограниченных страницах Chrome может запретить показ.
- В Ubuntu с GNOME и Wayland окно «Картинка в картинке» может уходить под другие окна. Их порядком управляет GNOME, а Chrome не даёт расширению закрепить окно средствами системы. Чтобы закрепить его вручную, щёлкните по нему, нажмите **Alt+Пробел** и выберите **«Всегда поверх» (Always on Top)**.
- Сохранённое положение окна может потребовать повторного выбора при изменении конфигурации мониторов.

## Данные и разрешения

Все данные хранятся локально в браузере. Расширение не делает сетевых запросов. Ссылки содержат адрес страницы и CSS-селектор выбранного блока: делитесь ими только если можно делиться исходным адресом страницы.

- Доступ к сайтам нужен для выбора, скрытия окружающей страницы, автоматических ссылок и маркеров сохранённого выбора.
- `tabs` нужен для переноса и возврата вкладки и определения её адреса.
- `storage` сохраняет выбор, размеры и настройку Auto PiP по сайтам. Состояние переноса хранится в `storage.session` и переживает остановку service worker.
- `scripting` подключает управление к уже открытым вкладкам.
- `contextMenus` добавляет команду в контекстное меню.
- `bookmarks` создаёт папку и закладки по кнопке ★.
- Доступ к сайтам также позволяет делать снимки по вашей команде; отдельное избыточное разрешение `activeTab` не запрашивается.

## Проверка для разработки

Сборка не нужна. Устанавливается непосредственно содержимое этой папки.

```powershell
node --check background.js
node --check content.js
node --check popup.js
python tests/smoke.py
python tests/player_layout.py
python tests/pip.py
python tests/pip.py --chrome
node tests/lifecycle.js
python tests/dashboard.py
```

Для последней команды нужны Python с пакетом `playwright` и установленный Chromium Playwright (`python -m playwright install chromium`). Тест запускает отдельный временный профиль и локальный HTTP-сервер; личный профиль браузера не используется.

Тест проверяет выбор и колесо мыши, iframe с другого домена, перехват `pointerdown` и `click` без переключения воспроизведения, отмену с фокусом внутри iframe, перенос без перезагрузки, интерактивность блока, скрытую полупрозрачную панель, сохранение и удаление геометрии, снимок PNG, закладку и автоссылку, возврат исходной вёрстки, повторный визит и восстановление вкладки после штатного закрытия отдельного окна, в том числе после перехода на другой адрес. PiP проверяется на обычном видео и во вложенном плеере с другого домена: сохранение документа и воспроизведения, исключение посторонних видео, возврат, закрытие PiP и запрет со стороны плеера. Скриншоты теста находятся в `tests/`.

Публичное описание оригинала: https://www.crx4chrome.com/extensions/cbgkkbaghihhnaeabfcmmglhnfkfnpon/

Глобальный проморолик с реальными действиями расширения: `docs/store/videos/global-promo-1.4.0.mp4`. Монтаж, сборка и текст для YouTube описаны в [docs/store/promo-video.md](docs/store/promo-video.md).

`python tools/marketing_assets.py` снимает реальную работу расширения на собственной демо-странице и создаёт пошаговые галереи: RU, EN и глобальную, по четыре PNG 1280×800. Для генерации нужны Python, Pillow и Playwright; в runtime-ZIP они не входят.
